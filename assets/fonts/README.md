# Fonts

Bitmap fonts for the LED matrix, from the classic X11 misc-fixed collection
(via [rpi-rgb-led-matrix](https://github.com/hzeller/rpi-rgb-led-matrix)).
The misc-fixed fonts are public domain; `6x10.bdf`'s own COPYRIGHT string
reads "Public domain terminal emulator font. Share and enjoy."

The board uses `6x10.bdf`. The others (5x8, 5x9, 6x9) are kept for
experimentation.
